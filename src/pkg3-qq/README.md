# 包3 · QQ 扩展（QQ包）

> 让爱莉接入 QQ——上班、外出也能聊天（文字+语音），还能给你干任务！
> 前提：先装好 包1（推荐再装 包2）。

## 安装（约 10 分钟）
1. 双击本包 **install.bat**（NapCat 会自动下载——钉死 v4.18.28 并做 sha256 校验，
   校验不过会拒绝安装转手动指引，需要联网约 2 分钟）
2. 按提示：启动 NapCat → **用 QQ 小号扫码登录**
3. 登录完成后：
   - 确保 DSH 在跑（双击桌面的 `start-elysia.bat`）
   - 运行分身：`python D:\AI\JARVIS\qq-elysia.py`
4. 用你的大号 QQ 加小号好友 → 发消息 = 和爱莉聊天！
   （只有安装时填进白名单的 QQ 号能聊；换人要改 `D:\AI\JARVIS\qq-config.json`
   里的 `allowed_users`，然后重启分身——**只改这一个文件就行**，
   插件/NapCat 都以它为唯一真源）

## 功能
- 💬 **私聊**：发消息爱莉就回
- 👥 **群聊**：@ 爱莉 才回，不吵群
- 📋 **任务**：直接说就行，爱莉是完整的 DSH，能读写文件、跑命令
- 🖼️ **看图**：QQ 里发图爱莉能看见（最多 3 张/张 ≤5MB，自动压到 400px；
  只接受 QQ 官方 CDN 的图）。**前提是默认模型支持视觉**——装包1 时的默认
  `deepseek-flash` 支持；若你换成了纯文本模型，爱莉会如实告诉你"看不了图"，
  换回支持视觉的模型即可
- 🔊 **语音**：回复短于 100 字会附语音条 —— **需要先装好 CosyVoice**（见下）

## 包内容
```
qq-elysia.py    # QQ 分身（消息收发+语音）
plugin/         # DSH 插件（QQ↔DSH 的桥，install.bat 会自动装进 DSH）
install.bat
README.md
```

## 常见问题
- **别人发消息没反应**：白名单外的一律不回（安全设计，就是安装时让你填的那个名单）。
  把 TA 的 QQ 号加进 `D:\AI\JARVIS\qq-config.json` 的 `allowed_users`，重启分身即可。
  白名单/口令只有这一个地方要改（插件每次注入都会重新读它）
- **爱莉说"名单没同步（403）"**：qq-config.json 的 `allowed_users` 和分身启动时读到的
  对不上了——改完配置**重启分身**就好
- **爱莉说"口令没对上（401）"**：`inject_token` 改过但分身还在用旧值——重启分身
- **没有语音**：先看分身后台的日志。多半是没装 CosyVoice —— 语音链路需要
  包2 里那个约 3GB 的模型（见包2 README 第 3 节）。没装时**文字照发**，不会丢消息
- **分身日志说"找不到 ffmpeg"**：语音转码和图片压缩都要 ffmpeg。装一个并让它在
  PATH 里（`winget install Gyan.FFmpeg`），或把 `ffmpeg.exe` 放进 `D:\AI\JARVIS\bin\`，
  重启分身。没有 ffmpeg 时图也能看（原图直传），只是费 token
- **重复消息**：分身已内置去重（10秒内同消息只回一次）
- **发图片被忽略/提示看不了图**：三种可能——① 图片域名不在 QQ 官方 CDN 白名单内
  （日志里有 `[图片] 非白名单域名`）；② 图下载失败（超过 5MB 或网络问题）；
  ③ 默认模型不支持视觉（分身会如实回"看不了图"）。按 ③ 的话去 dsh 的 Web 设置页
  把默认模型换成支持视觉的
- **NapCat 登录不了**：确认小号没在其他地方登录
- **分身一直 [断线] 重连**：看日志第一行 `[WS] 头参数名...`——脚本按 websockets
  版本自动选参数名并会在认错时自动翻面；手动兜底：`python -m pip install "websockets>=14"`

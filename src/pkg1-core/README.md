# 包1 · DeepSeek Harness（核心包）

> 这是基础包，所有人都能装。装完可以正常和 AI 对话。
> **小白完全不用担心，全程自动！**

## 第一步：拿秘钥（Key）（约 3 分钟）
1. 电脑或手机打开网址：**http://platform.deepseek.com/** （要输完整，带 http://）
   - 注意：**不是** www.deepseek.com（那是聊天网站），是 platform 开头的！
2. 用手机号注册登录（收验证码）
3. 进去后看左边菜单 → 点「**API Keys**」→「创建」→ 随便取个名字（比如"我的AI"）→ 确定
4. 会生成一串 **sk- 开头**的字母数字 → 点「复制」→ 先粘到记事本存好

> 小提示：新用户有免费额度，可以先不充钱试试；要充就充一点点，用多少扣多少。

## 第二步：安装（约 3 分钟，全自动）
1. 双击 **install.bat**（文件夹里就这一个文件，双击它）
2. 弹出蓝色 UAC 窗口 → 点「**是**」
3. 黑窗口自动干活（检查环境、缺啥装啥、失败自动换源重试）
4. 等它说「**请粘贴 DeepSeek API Key**」→ 把刚才的 sk-xxx 粘进去 → 回车
5. 全部搞定！浏览器自动打开 **http://127.0.0.1:3080**

## 第三步：开始用（每次开机）
- 电脑重启后，**双击桌面的「start-elysia.bat」**（安装时自动生成的启动器）
- 等 5 秒 → 浏览器自动打开 http://127.0.0.1:3080
- 或者直接开浏览器输 http://127.0.0.1:3080（安装时已设置开机自启，后台自动跑）
- 进去后：选工作区（D 盘新建个文件夹）→ 选预设 → 打字聊天！

## 常见问题
- **刷新后进不去**：dsh 在后台跑，等几秒再刷新；或双击桌面 start-elysia.bat
- **双击没反应**：右键 install.bat →「以管理员身份运行」
- **Key 无效**：复制时别漏字符，sk- 开头的完整一串
- **想让它变成"爱莉"**？下载 包2-爱莉包
- **想用 QQ 聊天**？下载 包3-QQ包
